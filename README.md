# Ruta de Aprendizaje Adaptativa de Matemáticas

Este proyecto implementa una plataforma web de aprendizaje adaptativo de matemáticas basada en un motor de estados determinista.

## Requisitos Previos
- Node.js (v20 o superior)
- Docker y Docker Compose (Recomendado)

## Ejecución con Docker (Recomendado)
Para iniciar la aplicación completa (Frontend, Backend y Base de Datos SQLite) ejecuta:

```bash
docker compose up --build
